# US-INFLATION-SPILLOVERS-TO-LATIN-AMERICA-PERSISTENT-POST-COVID-DYNAMICS-IN-INFLATION-CONNECTEDNESS
This repository presents the data and replication codes used to replicate the results of Quineche and Aguilar (2026), "US Inflation Spillovers to Latin America: Persistent Post Covid Dynamics in Inflation Connectedness"

The working paper version is available at http://dx.doi.org/10.2139/ssrn.6031214
